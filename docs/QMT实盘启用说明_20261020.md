# QMT 实盘启用说明

## 已完成的运行链

实盘档位为 `QMT_TRADING`。桌面启动后会同时启动交易引擎、量化后台同步代理和本机页面，并在交易日执行：

1. 14:30–14:55 每分钟读取量化后台当天的签名选股清单；
2. 收到清单后自动订阅入选股票及待卖持仓的 QMT Tick；
3. 从 QMT 合约详情核对可交易状态、当日涨跌停价和最小价格单位；
4. 按最新卖一价提交保护限价买单；超时先撤单，收到券商终态并重新核对账户后才按新行情重报；
5. 次一交易日按每笔实际成交成本执行止盈、止损和最晚卖出；
6. 15:30 起按 15 分钟间隔尝试日终封存与回传，直到本次桌面会话关闭。

程序每次启动都保持暂停。操作员登录页面、完成恢复核对并确认“启动实盘自动交易”后才会取得本次启动有效的报单权限。

## 首次配置

双击 `打开自动交易系统.cmd`。首次使用或原配置失效时，程序仍会打开完整操作台，顶部显示“尚未连接 QMT”，所有行情订阅和交易操作保持锁定。进入“系统设置”，点击“开始连接 QMT”；也可以使用启动器窗口里的“连接QMT”按钮。在接入页面选择量化后台生成的 `QMT_TRADING` 节点配置和包含 `xtquant\xttrader.py` 的 SDK 目录，点击“保存、检查并启动”。系统会自动识别本机已有的 SDK 路径。检查通过后程序保存非敏感路径、关闭安全会话并启动正式节点，以后双击可直接进入实盘操作台。

节点配置中的量化后台地址、节点身份、HMAC 凭据引用、计划签名公钥、策略版本、交易日历和 QMT 账户指纹必须与量化后台登记一致。密钥和操作员口令保存在 Windows Credential Manager，不写入启动设置。原有 `ATS_LIVE_NODE_CONFIG` 和 `ATS_QMT_SDK_ROOT` 环境变量仍兼容，但普通使用不需要手工设置。

若要查看完全离线的页面演示，使用 `打开模拟演示.cmd`。模拟演示和正式入口使用不同的账户、配置和数据目录；正式入口缺少配置时显示未连接状态，无法取得任何交易权限。

## 页面设置

首次进入“尾盘策略”保存：当日最大买入、单股上限、单笔上限、撤单等待、重报次数、止盈、止损、最晚卖出、最大亏损和最多持仓数。实盘引擎在启动时装载这些限制，因此首次保存或修改后需要退出并重新打开系统。

“紧急清仓策略持仓”只处理本系统通过已核对成交记录建立的持仓批次。它会先撤销未完成的系统委托，等券商确认后再按最新买一价卖出，不会处理账户原有手工持仓。

## 当前现场条件

仓库里的旧调试配置使用 `https://127.0.0.1:1`、`preview-unconfirmed` 和临时环境凭据，只能用于只读连接检查，不能改名后作为正式实盘配置。正式启动前必须由量化后台生成并登记真实节点资料。
