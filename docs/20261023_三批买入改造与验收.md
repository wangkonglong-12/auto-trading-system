# 自动交易系统：三批买入改造与验收

日期：2026-10-23。分支：`codex/tail-buy-console`。源码版本：`0.1.0.dev56`。

## 交付范围

本地源码已实现新操作台与三批“优”信号买入模式。今日交易、策略持仓、历史记录、设置四个入口；真实QMT资金、持仓代码及名称读取通过。主列表删除首次识别和说明列，使用实际成交时间、加权均价和金额；完成、未买入、部分成交、委托中分别统计。历史页当前只展示QMT当日成交，跨日历史仍在量化后台。

三批各自签名、不可替换，共用每日股票数和资金上限，同股同日一个持久化目标；未知在途状态不会释放额度。新批到达不自动授予权限。撤回状态持久化，重启暂停；补接每个早批都独立验签，重报只处理同一目标剩余量。卖出留空时不创建退出执行器，保存新版设置关闭紧急清仓。旧设置不会静默迁移或覆盖。

源码边界及迁移见[ADR](adr/ADR-TAIL-001-三批优信号与本机买入边界.md)，界面检查见[设计验收](../design-qa.md)。量化配套修改在相邻`ai-stock-assistant`项目的交易模块，未修改选股算法、全局调度或其他研究模块。

## 复核与修正

- 保留唯一引擎所有者、单SDK线程、Journal先提交后报单、账户/交易日/节点代际绑定。三批相同风险预算、窗口、策略版本及授权方向必须一致；同批不同正文拒绝。
- 逐股去重索引先持久化，重启可恢复目标写入中断时的记录。跨批股票名额依据实际成交和未决委托共同约束；部分成交不误计为全部完成。手工交易不计入策略买入进度，不接管未知归属持仓。
- 修正日终导出新增多批字段对旧单计划缺失/篡改检查的影响；三批结果使用独立记录编号，同股后批明确记为重复信号。
- 修正整元报价可能生成科学计数法字符串的问题；买入行情接收及有效期检查使用同一高精度单调时钟，避免Windows低精度时间戳误拒绝连续报价。
- 账户查询失败、过期、截断及会话失效不展示为零；授权结果未知只补查原请求，不重复提交。慢启动预览被停止操作隔离，账户切换丢弃旧异步响应；确认窗可键盘操作及取消。
- 只读展示与核验/报单隔离，股票名称缺失不编造名称。开发用只读/Mock操作员默认口令改为满足现有长度校验的`Desktop-570612-Local`；不修改实盘口令校验器或凭据。当前预览已登录真实只读节点。
