# 自动交易系统完成情况与现场验收清单

更新日期：2026-10-21

## 1. 当前结论

个人尾盘自动交易系统的代码开发、页面整改、代码复核、自动化测试和 Windows 打包已经完成。系统只保留六个日常入口：首页、QMT 账户、尾盘策略、交易监控、消息与日志、系统设置。

正式业务闭环已经接入 `QMT_TRADING`：

`量化后台选股计划 → 自动订阅 QMT 行情 → 风控检查 → 买入 → 未成交自动撤单 → 核对后按剩余数量重报 → 成交成本入账 → 次日止盈/止损/到时卖出`

当前只差目标机器的现场配置和一笔经过用户明确授权的小额真实报单、撤单、成交回报验收。仓库不保存真实后台地址、HMAC 密钥、计划签名密钥和账户现场参数，因此不能用虚构资料代替正式配置。本轮没有发送任何真实委托。

## 3. 页面使用流程

1. 双击 `打开自动交易系统.cmd`；首次使用先在自动打开的“系统设置｜QMT 接入”页面保存并检查本机接入配置。
2. 正式节点启动后，在“系统设置”登录并查看 QMT、量化后台和交易引擎状态。
3. 在“尾盘策略”设置买入额度、撤单等待、重试次数、止盈、止损和最晚卖出时间。
   实盘运行中修改设置后，页面会要求关闭主窗口并重新打开；重启后仍保持暂停，需要再次人工启动。
4. 首页查看今日是否收到选股计划以及系统是否允许交易。
5. “交易监控”查看选股、行情订阅、信号、委托、撤单和成交。
6. “消息与日志”查看失败原因和需要处理的异常。
7. 需要立即停止时使用首页“暂停全部自动交易”；需要退出策略持仓时使用“紧急清仓策略持仓”。

## 4. 现场启用前必须提供的资料

- 量化后台正式地址和节点身份。
- 节点 HMAC 凭据引用。
- 量化后台计划签名私钥对应的可信公钥。
- 正式交易日历、账户号、QMT `userdata_mini` 路径和 XtQuant SDK 路径。
- 券商端已实际生效的 QMT 函数交易权限。

读取到资金、持仓、委托或成交，只能证明账户查询通道可用，不能单独证明函数交易报单权限已生效。权限必须通过券商确认或经过明确授权的小额真实委托验证。

## 6. 现场验收步骤

1. 填写正式配置并安装双方密钥。
2. 启动量化后台，确认当天签名计划可以被交易节点读取。
3. 启动 QMT 和自动交易系统，确认页面显示 `QMT_TRADING`、账户已连接、行情订阅正常。
4. 先保持零额度完成计划、行情、风控和页面检查。
5. 用户明确授权具体股票、数量、价格范围和时间窗后，进行一笔小额真实报单、撤单及回报核对。
6. 核对券商终端、系统委托、成交和策略持仓账本四处数据一致后，才能确认现场实盘验收完成。
