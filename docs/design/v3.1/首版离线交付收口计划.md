# 首版离线交付收口计划

本轮用户授权连续完成以下四项，按顺序验收。范围是可安装、可操作的模拟验收版。
正式策略由用户后续决定；真实QMT适配、目标机验收及实盘准入另行完成。

| 编号 | 固定交付项 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| F1 | 正常进程模拟交易闭环 | 计划接收、模拟买卖、独立券商事实、重启核验、跨日持仓、日终回传；重启保持暂停 | DONE（模拟工程） |
| F2 | 量化V2日记录查询与页面 | 按账户/日期显示当前已应用版本；委托/成交/持仓/资产/执行结果/同步状态；隔离与权限回归 | DONE |
| F3 | 样例账单导入及基础对账 | 导入、重复幂等、更正、费用与成交核对、差异展示；明确样例与真实账单区别 | DONE（SAMPLE） |
| F4 | 安装包及贯通验收 | 隔离启动演示F1至F3，断网补传、重启、急停；可复现操作文档及制品证据 | DONE（离线发行） |

实施边界：Windows默认配置继续零额度；显式FICTIONAL_ACCEPTANCE_ONLY配置才启用测试额度，
使用paper-账户别名、Mock券商和模拟行情，保留本地认证/恢复确认/授权。
量化端修改限定auto_trading子模块及其测试、独立迁移和文档。原有业务代码和数据保留。
所有验证使用隔离数据；生产数据库、凭据、已注册任务、真实QMT保持原状态。

此前“继续恢复候选激活”的排期由本表替代。在线维护、自动留存、完整Tick录制回放、
扩展维护页面排入后续版本；真实交易所需的数据保全与风险验收仍保留为上线条件。
