## 4. 重复执行

新环境准备（目标目录必须不存在，父目录已存在）：

```powershell
./scripts/prepare-qmt-readonly.ps1 `
  -Python <Python3.11绝对路径> `
  -Destination <全新独立环境目录>
```

只读交易与行情全链路：

```powershell
./scripts/run-qmt-readonly.ps1 `
  -EnvironmentRoot <已准备的环境目录> `
  -QmtRoot 'E:/中金财富QMT个人版交易端' `
  -OutputDirectory <全新报告目录绝对路径> `
  -Scenario CLOSED -Seconds 5
```

仅检查行情时追加`-MarketOnly`；交易时段明确使用`-Scenario ACTIVE`，要求收到有效回调。示例标的600000.SH只用于行情验证，不表示买卖建议。

多账户时使用`-AccountFingerprint <发现报告中的16位指纹>`，不接受完整账号命令行参数。输出中的`execution.json`为父进程最终结论；其余connection/snapshot/tick为对应阶段不可变报告。单次默认最大等待75秒，最短63秒、最长150秒；超时生成错误结果。SDK本身可能生成通信队列或本地日志，这属于接口运行文件，不是订单或交易配置修改。

使用同一稳定session组再次执行时，与前次连接至少间隔3秒。SessionId为三段基数，最大2147483645。同一资金账号可以同时具有股票、沪港通与深港通类型，发现阶段按“账号+类型”判重，仅从普通股票类型中选择本轮目标。
