# TST-004 Mock Broker异常矩阵验收记录

## 验收结论

TST-004完成。`MockBrokerGateway`对受理、拒单、部分成交、撤单、超时、重复回调和乱序回调
七类场景形成了独立、确定性、可重复执行的集成验收矩阵，且与订单意图持久化门和真实
SQLite/WAL组合测试一并通过。

## 验收矩阵

| 场景 | 验收结果 |
|---|---|
| 受理 | 请求序号单调，`ACKED`事实可查询 |
| 拒单 | 原因完整，形成`REJECTED`终态事实 |
| 部分成交 | ACK、订单更新、成交事实及累计/剩余数量一致 |
| 撤单 | 未成交与部分成交状态正确；撤单拒绝保留原订单事实 |
| 超时 | 提交/撤单的应用前与应用后语义明确；结果未知时先查询且阻断同标识重报 |
| 重复 | 回调可逐字重复，Broker订单与成交事实保持唯一 |
| 乱序 | 成交先到、部分成交后到、ACK最后到的交付可复现，最终查询事实一致 |
